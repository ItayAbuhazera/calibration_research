# Representation atlas, distance diagnostics and selective correction — frozen specification

**Frozen:** 2026-09-21, before any atlas neighbour file, atlas statistic, shortlist, metric selection, gate or evaluation output was
produced or inspected. Text above `<!-- END FROZEN -->` is hashed (`results/atlas/freeze_manifest.json`); results and
interpretation are appended below the marker only. Namespace `results/atlas/`; nothing under `results/layer_pilot/`,
`results/residual_study/`, `results/fv_dac/` or `results/studyAB/` is written. Code for submitted jobs runs from immutable snapshots
(`snapshots/atlas_v1_*`).

This is a **newly authorized diagnostic program**. It does not reopen the FV-DAC, layer-pilot or residual-evidence studies or their
continuation gates; their verdicts stand. It is not a novelty claim and not committed to DAC or RGCL as a final method. A
well-supported explanation of failure is a valid outcome. **Primary outcomes are ACC, NLL and sum-convention multiclass Brier; ECE,
adaptive ECE, classwise ECE and AURC are diagnostics only** (the previous ECE continuation gate is not inherited).

## 0. Questions

1. Which layer/pooling combinations supply correct alternatives on examples the base classifier gets wrong?
2. Are those alternatives complementary to output-space alternatives rather than duplicating the base model?
3. Does spatial pooling retain decision-relevant information lost by GAP?
4. Does angular distance, covariance structure, or feature norm explain success/failure?
5. Can a clean-trained rule separate useful replacements from harmful ones?
6. Can the result improve accuracy without losing NLL/Brier, at useful inference cost?

CIFAR-C is a same-vocabulary corruption shift; detecting atypical examples is not the same as finding correctable errors; cluster separation
of training data is not evidence of correction capability.

## 4. Experiment A — all-block × three-pooling atlas

**Sites (34, verified from the model):** `stem` = `relu(bn1(conv1(x)))` (64×32×32, marked control), and every Bottleneck output (`layer1.0–2` 256×32×32, `layer2.0–3` 512×16×16, `layer3.0–22` 1024×8×8, `layer4.0–2` 2048×4×4), all post-activation. `avg_pool2d(layer4.2, 4)` equals GAP of `layer4.2` (tested) → marked "final pooled" control, not a 35th site. Logits = separate output-space control. No internal convolutions.
**Pooling** `a_{l,P}` (pre-L2): GAP (`C`); grid2 = 2×2 adaptive average (`4C`); SPP = concat over valid levels `q∈{1,2,4}` (`q ≤ min(H,W)`; all maps here are ≥ 4×4, so all three levels are valid everywhere; any invalid level would be dropped and logged) of `flatten(avg_pool_q)/q`, then `/√(#levels)` (`21C`). The weights are fixed, not learned; they do not equalize signal energy; per-level squared norms are recorded (`spp_level_sq_norms`). Repository `FixedSizeSPP_JL` / `ChannelFirstSPP_JL` project/max-pool and are **not** equivalent, so they are not used. `v = a/max(‖a‖,ε)`, ε=1e-12; zero-vector counts recorded. **No** PCA/random projection/truncation/quantization; float32 features, TF32 off, exact batched GPU distances + top-k, ties resolved by (distance, bank index) via a stable sort over the 64 smallest candidates.
**Diagnostic classifier:** unit-L2 Euclidean, global `k = 50` (no sweep), `p_geo(c|x) = (n_c + α π_c)/(k+α)`, `α = 1`, `π` = source-bank class prior, `j = argmax p_geo` with lowest-index tie-breaking. Compared with the identical construction in centered, unit-normalized **logit** space. Per query set record local true-label proportion, geometric accuracy, smoothed NLL/Brier, true-class rank (deterministic tie order), global k-th radius, `W/H/U` vs the base prediction, candidate accuracy among base errors, harm rate among base-correct examples, net utility `(W−H)/n`, intervention precision `W/(W+H+U)`, decisive precision `W/(W+H)`, rescued fraction `W/#base errors` and every count; undefined denominators are `None`, never 0.
**Source-only shortlist (before corruption metrics are opened):** per pooling family, the site with maximum clean-**selection** net gain `(W−H)/1250`; ties → lower selection smoothed NLL → lower measured query cost → fixed depth order. The best is kept even if every gain is negative (flagged). ≤ 3 candidates per checkpoint. Number of searched configurations recorded (34×3 = 102). A paired-resampling stability table (200 resamples of selection rows, descriptive, no retuning) is added. The selected validation gain is optimistic and is not an effect estimate. The **best layer per corruption** is computed only as an explicitly labelled *target-labelled oracle ranking* and never selects candidates for B/C.

## 5. Experiment B — distance geometry (≤ 3 candidates + output control)

Same bank, `k=50`, smoothing and query IDs: (1) **unit_l2** (Experiment A metric); (2) **raw_l2** — Euclidean on the pre-L2 vector `a` (norm preserved; no per-coordinate standardization; a single scalar rescaling would not change neighbours); (3) **mahalanobis** — source-only covariance `Σ = (1−γ)[U_r Λ_r U_rᵀ + s²(I−U_rU_rᵀ)] + γ m I`, `r = min(256, d, n_ref−1)`, `γ = 0.1`, `s²` = mean residual variance over all omitted directions, `m` = mean marginal variance, eigenvalue floor 1e-12, top-r subspace by `torch.svd_lowrank` (fixed `niter=6`, exact `eigh` when `r ≥ d`), inverse via the decomposition so the orthogonal residual still contributes. No class-specific covariances, no shrinkage/rank sweep. Rank, shrinkage, top eigenvalues, explained fraction and condition number are recorded. Cosine/squared-Euclid-on-unit vectors are not counted as separate evidence. This compares specified metric constructions, not a pure causal isolation of covariance. The same three metrics run on the full-logit reference bank (label-access control). One metric per pooling family and one output-space metric are chosen by the Experiment-A selection rule (ties: unit_l2 < raw_l2 < mahalanobis) and **frozen** (`metric_selection.json`, read-only) before target outcomes are opened.

## 6. Experiment C — small clean-trained gate

Candidate generator fixed first: per candidate `i = argmax(base logits)`, `j = argmax p_geo` (metric from §5); no intervention when `j = i`. Target `D = 1{j=Y} − 1{i=Y}`. Ridge `min mean((D − b − x·w)²) + λ‖w‖²` (unpenalized intercept) on standardized features, trained on clean-fit **disagreements** only (counts reported; if fewer than 5 disagreements exist the exact no-intervention policy is returned). Feature sets for the **same** candidate: **F0** = centered logits, one-hot base and candidate class, `p_base(i)`, `p_base(j)`, base top-two logit margin, `z_j − z_i`, predictive entropy; **F1** = F0 + `p_geo(j) − p_geo(i)`, entropy of `p_geo`, k-th radius, pre-L2 feature norm (for the logit-space candidate the norm of the centered logits). λ ∈ {0.01, 1, 100}, prediction clipped to [−1, 1], `θ ∈ {0, 0.02, 0.05, 0.10, 0.20}` plus never-intervene; same search for F0 and F1; selection on clean-selection rows by maximum net accuracy gain, ties → fewer interventions → stronger regularization (never = ∞). Never-intervene guarantees ≥ 0 on the selection rows; a rejection by clean selection is preserved. An F0 gate on a hidden-derived candidate is **not** a logit-only system; the separate logit-space candidate pipeline plus VS/matrix-scaling controls give the full output-only comparison. Probabilities: `q_raw = (1−g) q0 + g p_geo`, `q0` = native DAC refit on **FIT rows only** (five sources, same objective/optimizer as `DensityAwareCalibrator.fit`), argmax = `i`; `p_geo` argmax = `j`. Uncalibrated branch mixtures may be poorly calibrated; accuracy gains are not evidence of calibration.

## 7. Experiment D — probability quality, evaluation, cost

**Final temperature** `q = softmax(log q_raw / T)`, one `T>0` per pipeline fitted on the **calibration** split after everything else is frozen (primary: minimize NLL; separately labelled sensitivity: minimize Brier; 1-D bounded search on `log T ∈ [log 0.05, log 20]`); argmax-preserving. Pre- and post-temperature results reported. Controls refit on compatible roles (FIT rows; hyper-parameters on selection rows): base, TS, VS (existing class), regularized matrix scaling (`λ∈{1e-4,1e-2,1,100}`, ridge toward identity, chosen on selection NLL), native DAC (FIT-only refit); historical full-5 000-row baselines are context only. Each also receives the final-temperature opportunity. **Evaluation** (after all choices are frozen): all 10 000 clean test images and all 12 development cells, seeds 2 and 4. Primary: ACC, NLL, Brier (sum convention); secondary: 15-bin ECE, adaptive ECE, classwise ECE, AURC (`utils/unified_metrics.py`). No composite score. Per split/condition/seed: `W/H/U`, total flips, `W/total`, `W/(W+H)` (decisive precision), net flips, rescued fraction, ground-truth ranks before/after computed from float64 probabilities. **Cost:** latency at batch 1 and 256 (backbone + pooling + exact bank search + native-DAC radii + gate + temperature), warm-up 20, CUDA-synchronized, hardware/dims/bank bytes/peak memory; no ANN/compression.
**Practical targets (research-budget, not significance thresholds):** a candidate hidden-F1 pipeline (post-T) reaches ≥ **+0.5 pp** over base and ≥ **+0.25 pp** over the strongest relevant output control (max macro corruption accuracy among {VS, matrix scaling, output-candidate F0, output-candidate F1}), with the same direction in both checkpoints and non-worsening NLL and Brier relative to that control. Missing them does not stop the descriptive atlas.

## 8. Refutation conditions (declared before outcomes)

* **H-A (spatial information):** a clean-selected grid2 or SPP candidate exceeds the clean-selected GAP candidate in macro corruption candidate net utility by ≥ 0.5 pp in **both** checkpoints. Refuted otherwise.
* **H-B (complementarity):** for the best hidden candidate, repairs not achieved by the output-space candidate exceed harms not incurred by it (`unique W − unique H > 0`, absolute counts, macro cells) in both checkpoints. Refuted otherwise.
* **H-C (metric):** raw_l2 or mahalanobis beats unit_l2 on clean-selection net gain by ≥ 0.5 pp for ≥ 1 pooling family in both checkpoints. Refuted otherwise.
* **H-D (gate):** for the same hidden candidate, F1 beats F0 in macro corruption accuracy by ≥ 0.10 pp in both checkpoints, and hidden-F1 beats output-F1. Refuted otherwise.
* **H-E (practical):** the §7 targets. Refuted otherwise.
Each result is reported with its counts; a failed H does not trigger new configurations.

Oracle-union quantities (evaluation-only label oracle over a frozen candidate set) and learned-policy quantities are reported separately and never conflated. No conclusion of "no information" from one metric or gate; no "sample size is the cause" from strong regularization alone; unidentified explanations are listed.

## 14. Interpretation (appended; separate from §13's measurements)

* **Supported (development, 2 checkpoints):** hidden mid-network representations *do* contain correct alternatives on 10–14 % of base errors under these corruptions (vs 2.5 % for a logit-space kNN), and spatial pooling raises that rate and lowers the harm rate at the same layer (SPP `layer3.21` 0.129 / 0.384 vs GAP `layer3.19` 0.097 / 0.51). Those alternatives are, however, not distinguishable from harmful replacements by anything used here: the clean-selection rule chose `layer4` candidates whose information largely duplicates the head, and a small ridge gate on ≤ 151 clean disagreements learned essentially "intervene or not".
* **Weakened:** that a clean-selected hidden candidate + small gate beats matched output-space pipelines (H-A…H-E refuted); that Mahalanobis (this estimator) helps on high-dimensional hidden features; that probability quality is preserved by intervention (raw NLL/Brier never beat native DAC; clean-fitted final temperature hurt under shift).
* **Unidentified:** whether a gate with more/better clean supervision, a different candidate-selection rule (the clean rule preferred `layer4`), or a different metric could turn the mid-network alternatives into net gains; whether the oracle-visible `layer3` alternatives are correctable from clean information at all; whether the failure is candidate information (it is not absent), intervention selection, or shift transfer. The data are *consistent with* an intervention-selection/transfer limitation (alternatives exist, harm on base-correct examples is 38–52 %, gate signal is tiny) but do not separate the two, and the clean-selection source rule is itself a candidate-choice limitation.
